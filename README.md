# Wiki Course

لینک یک مقاله‌ی ویکی‌پدیا را بده. پیش‌نیازها، قدم‌های بعدی و مطالب مرتبط را با تصویر، خلاصه، نمره و دلیل به‌شکل یک مسیر یادگیری می‌گیری. هر چه بلدی را تیک می‌زنی، فلش‌کارت مرور می‌کنی و آزمون می‌دهی. رودمپ را خروجی می‌گیری یا برای ChatGPT/Gemini/Claude پرامپت آماده کپی می‌کنی.

```bash
npm install
npm run dev        # http://localhost:5173
npm run check      # assertهای منطق (استخراج JSON، لایتنر، streak، خروجی‌ها)
npm run build      # همان چیزی که Vercel می‌سازد (dist/)
```

## چطور کار می‌کند
- **سایت کاملاً استاتیک است.** مرورگر مستقیم ویکی‌پدیا و gateway هوش مصنوعی (آروان → Gemini 2.5 Flash-lite، سازگار با OpenAI) را صدا می‌زند. هر دو CORS دارند. سرور و دیتابیس ندارد.
- **کلید هوش مصنوعی** را در ⚙️ تنظیمات وارد کن: آدرس gateway تا `/v1`، API key و مدل. فقط در localStorage همان مرورگر می‌ماند؛ نه در کد است، نه در گیت، نه در فایل پشتیبان.
- **ساخت دوره** — `src/lib/build.ts`:
  1. خلاصه، تصویر و لینک‌های مقدمه‌ی مقاله از ویکی‌پدیا خوانده می‌شود.
  2. مدل پیش‌نیاز، پس‌نیاز و مرتبط را با نمره‌ی ۰–۱۰۰ و دلیل برمی‌گرداند.
  3. هر عنوان در ویکی‌پدیا پیدا می‌شود؛ اگر عین عنوان نبود، با جستجو.
  4. اگر پاسخ ناقص یا خراب بود (gateway گاهی جواب را می‌بُرد)، تا ۶ بار دوباره پرسیده می‌شود.
- **فلش‌کارت و آزمون** به‌ازای هر موضوع و فقط وقتی بخواهی ساخته می‌شوند. ورودی متن خود مقاله است و خروجی نکات کلیدی، ۶ کارت و ۴ سؤال. مرور با جعبه‌های لایتنر است (۱، ۲، ۴، ۸، ۱۶ روز). آزمون با ۷۵٪ یعنی «بلدم».
- **ذخیره:** پیشرفت، کتابخانه و یادداشت‌ها در localStorage هستند و دوره‌ها و فلش‌کارت‌ها در Cache Storage. برای انتقال به گوشی یا احتیاط: ⚙️ → پشتیبان‌گیری / بازیابی.
- دوره‌های نمونه با خود سایت منتشر می‌شوند: متن هر دوره در `public/courses/` و فهرستشان در `src/data/samples.json`. نمونه‌ی تازه بساز با: `npm run build:course -- <wikipedia url>` (از `.env`: `AI_BASE_URL`، `AI_API_KEY`، اختیاری `AI_MODEL`). `en-Linear_algebra.json` دستی ساخته شده است.

## انتشار روی Vercel
مخزن را در GitHub push کن و در Vercel: **Add New → Project → Import** → Deploy. Vite خودکار تشخیص داده می‌شود و env لازم نیست. بعد از انتشار، روی هر دستگاه یک بار ⚙️ را پر کن.
